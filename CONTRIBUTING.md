# Contributing

The data is generated from the W3I database (a one-way export), so files in `data/` are not edited directly.

- **Corrections and new records:** open an issue with the matching template and include a public source link. Accepted changes enter the next release.
- **Removal requests:** use the removal template or write to support@w3i.network. Include the file and record id.
- **Code and docs:** pull requests for `analysis/`, `docs/` and the README are welcome.

Do not post phone numbers, private emails, messenger handles or any non-public personal data in issues or pull requests.
